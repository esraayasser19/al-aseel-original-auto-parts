# Al Aseel Original Auto Parts

**Al Aseel Original Auto Parts** is an Arabic e-commerce platform for browsing and selling original automotive spare parts.

## About the Project

The platform allows customers to easily find spare parts by **category, brand, and car model**. It provides a responsive and user-friendly interface with an Arabic RTL design.

The project also includes an **admin dashboard** for managing products, categories, brands, car models, and promotional banners.

## Features

* Browse spare parts by category.
* Browse products by automotive brand.
* Explore car models and their available parts.
* Search for products.
* Responsive design for all devices.
* Arabic RTL interface.
* Shopping cart functionality.
* WhatsApp contact and product sharing.
* Admin dashboard for content management.

## Technologies

* React.js
* JavaScript
* CSS
* Supabase
* React Router

## Project Goal

To provide a simple and organized online shopping experience for customers looking for original automotive spare parts.
